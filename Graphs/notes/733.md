
# LC 733 — Flood Fill

## Pattern
Grid DFS / Connected Component Traversal

## Core Idea

Imagine an image as a grid of colored pixels.

Starting from `(sr, sc)`, change the color of every connected pixel that has the same original color.

Only the four adjacent directions count:
- Up
- Down
- Left
- Right

Diagonal cells are not included.

## Approach

1. Store the starting pixel's color in `originalColor`.
2. If `originalColor == color`, return the image immediately.
3. Start DFS from `(sr, sc)`.
4. In DFS:
    - Stop if the coordinates are outside the grid.
    - Stop if the current pixel does not match `originalColor`.
    - Change the current pixel to the new color.
    - Explore all four directions.
5. Return the modified image.

## Why Store the Original Color?

We must change only pixels belonging to the starting pixel's original-color region.

For example:

Image:
1 1 1
1 1 0
1 0 1

Starting at `(1, 1)` with new color `2`, only the connected `1`s are changed.

The `0`s and the separate `1` at the bottom-right remain unchanged.

## Why Change the Pixel Before Recursion?

`image[row][col] = color` marks the pixel as processed.

This prevents DFS from repeatedly processing it through neighboring cells.

Because the new color differs from the original color, the existing color check also prevents revisiting the changed pixel.

## Important Edge Case

If the starting pixel already has the requested color, return immediately.

Without this check, the DFS could keep treating changed pixels as original-color pixels when both colors are identical, causing repeated traversal and potentially infinite recursion.

## Common Mistakes

1. Forgetting boundary checks.
    - Recursive calls can go outside the grid.

2. Checking against the new color instead of the original color.
    - The original color defines which pixels belong to the region.

3. Forgetting to update the pixel before exploring neighbors.
    - This can cause repeated processing.

4. Exploring diagonal directions.
    - The problem uses four-directional connectivity only.

5. Forgetting the `originalColor == color` check.

## Complexity

Let `m` be the number of rows and `n` be the number of columns.

Time: O(m × n) worst case.

Every pixel may be visited in the connected region.

Auxiliary space: O(m × n) worst case.

The recursive DFS call stack can grow to the size of the region.

## Interview Takeaways

- Grid traversal is graph traversal: each cell is a node, and adjacent cells are its neighbors.
- DFS can modify the grid directly to mark visited cells.
- Always identify the condition that allows traversal to continue.
- Check whether the replacement value equals the original value.
- Consider recursion depth for very large grids.
