
# LC 841 — Keys and Rooms

## Pattern
Graph DFS — Reachability

## Approach

1. Create a `visited` array for all rooms.
2. Start DFS from room `0`, because it is the only initially accessible room.
3. Mark the current room as visited.
4. Iterate through the keys available in the current room.
5. If a neighboring room has not been visited, recursively call DFS on it.
6. After DFS finishes, check the entire `visited` array.
7. If any room remains unvisited, return `false`. Otherwise, return `true`.

## Important Code

### Starting DFS

```java
dfs(visited, 0, rooms);
```

We start from room `0` and explore every room reachable from it.

### Marking a room visited

```java
visited[node] = true;
```

This prevents repeatedly exploring the same room.

### Exploring keys

```java
for (int neighbor : rooms.get(node)) {
    if (!visited[neighbor]) {
        dfs(visited, neighbor, rooms);
    }
}
```

`rooms.get(node)` gives us the keys available in the current room.

Each key identifies another room we can visit.

### Checking all rooms

```java
for (boolean ans : visited) {
    if (ans == false) {
        return false;
    }
}
return true;
```

If even one room remains unvisited, it cannot be reached from room `0`.

## Example

Input:

```text
rooms = [[1], [2], [3], []]
```

Traversal:

```text
0 -> 1 -> 2 -> 3
```

Visited array:

```text
[true, true, true, true]
```

Output: `true`

## Edge Cases

### 1. Only one room

```text
rooms = [[]]
```

Output: `true`

Room `0` is already accessible.

### 2. An unreachable room

```text
rooms = [[1], [], [0]]
```

Output: `false`

Room `2` cannot be reached from room `0`.

### 3. A cycle

```text
rooms = [[1], [0]]
```

Output: `true`

The visited check prevents infinite recursion between rooms.

### 4. Empty key list

A room with no keys is valid. DFS simply finishes exploring that room.

## Common Mistakes

1. Forgetting `visited[node] = true`, which can cause infinite recursion when cycles exist.
2. Calling DFS on already visited neighbors.
3. Starting DFS from every room instead of room `0`.
4. Returning `true` immediately after DFS without checking whether every room was visited.
5. Confusing the current room's keys with the rooms themselves.

## Complexity

Let V = number of rooms and E = total number of keys.

Time: O(V + E)

Each room is visited at most once, and each key is examined at most once.

Space: O(V)

The visited array takes O(V), and the recursive DFS stack can take O(V) in the worst case.

## Interview Takeaway

When asked whether all nodes are reachable from a given starting node, think of graph DFS or BFS.

- Nodes: Rooms
- Edges: Keys
- Starting node: Room 0
- Reachability check: Visited array
