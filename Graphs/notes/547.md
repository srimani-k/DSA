
# LC 547 — Number of Provinces

## Pattern
Graph DFS — Connected Components using an Adjacency Matrix

## 1. Problem Understanding

We are given an `n × n` matrix called `isConnected`.

- `isConnected[i][j] == 1` means city `i` is directly connected to city `j`.
- `isConnected[i][j] == 0` means there is no direct connection.
- A province is a group of cities connected directly or indirectly.

We need to count the number of provinces.

## 2. Approach

1. Find the number of cities using `isConnected.length`.
2. Create a `visited` array to track visited cities.
3. Loop through every city.
4. If a city is not visited:
    - Increment `count`, because we have discovered a new province.
    - Start DFS from that city.
5. DFS marks the current city visited and explores every directly connected, unvisited city.
6. DFS continues until every city in that province has been explored.
7. After the outer loop finishes, return `count`.

## 3. Why Does count++ Happen Before DFS?

```java
if(!visited[i]){
    count++;
    dfs(isConnected,i,visited);
}
```

An unvisited city means we have found a city belonging to a province that has not yet been explored.

We increment the count once, then DFS visits all cities belonging to that province.

When the outer loop encounters those cities later, they are already visited, so the count does not increase again.

**Key idea:** One DFS traversal discovers one new province.

## 4. Understanding the DFS

```java
visited[node] = true;

for(int neighbor=0; neighbor < isConnected.length; neighbor++){
    if(isConnected[node][neighbor]==1 && !visited[neighbor]){
        dfs(isConnected,neighbor,visited);
    }
}
```

The matrix is an adjacency matrix, not an adjacency list.

Therefore, to find the neighbors of `node`, we scan its entire row.

We recurse only when:
- The current city is connected to the neighboring city.
- The neighboring city has not been visited.

## 5. Example

Input:

```text
isConnected = [
  [1,1,0],
  [1,1,0],
  [0,0,1]
]
```

Connections:
- City 0 is connected to city 1.
- City 1 is connected to city 0.
- City 2 is isolated from cities 0 and 1.

Traversal:
1. Start at city 0: count = 1. DFS visits cities 0 and 1.
2. City 1 is already visited, so skip it.
3. City 2 is unvisited: count = 2. DFS visits city 2.

Output:

```text
2
```

## 6. Edge Cases

### Case 1: One city

```text
[[1]]
```

Output: `1`

There is one province.

### Case 2: All cities connected

```text
[
  [1,1,1],
  [1,1,1],
  [1,1,1]
]
```

Output: `1`

All cities belong to one province.

### Case 3: No cities directly connected to other cities

For three isolated cities:

```text
[
  [1,0,0],
  [0,1,0],
  [0,0,1]
]
```

Output: `3`

Each city forms its own province.

### Case 4: Indirect connections

If city 0 connects to city 1, and city 1 connects to city 2, all three belong to the same province—even if city 0 is not directly connected to city 2.

DFS handles this through recursive traversal.

## 7. Common Mistakes

1. **Incrementing count for every city.**
   Increment only when `!visited[i]`.

2. **Forgetting to mark a city visited.**
   This can cause repeated traversal or infinite recursion when connections form cycles.

3. **Scanning the wrong matrix row.**
   `isConnected[node][neighbor]` checks whether the current city connects to the neighboring city.

4. **Confusing adjacency matrix with adjacency list.**
   Here, neighbors are discovered by scanning all columns in a row.

5. **Assuming only direct connections count.**
   Provinces include cities connected indirectly as well.

## 8. Complexity Analysis

Let `n` be the number of cities.

### Time Complexity: O(n²)

The outer loop examines all `n` cities. During DFS, each visited city scans a row of up to `n` entries.

Across all cities, the total work is O(n²).

### Auxiliary Space Complexity: O(n)

- Visited array: O(n)
- Recursive DFS stack: O(n) in the worst case

The input adjacency matrix itself occupies O(n²) space, but it is not additional space created by the algorithm.

## 9. Interview Takeaway

Ask yourself:

1. What are the nodes? Cities.
2. How are connections represented? Adjacency matrix.
3. What does one DFS traversal discover? One complete province.
4. When should count increase? When we find an unvisited city.
5. Why do we need the outer loop? The graph may contain disconnected components.

**Recognition pattern:** Counting connected components in a graph represented by an adjacency matrix.
