
# LC 695 — Max Area of Island

## Pattern
Grid DFS + Connected Components + Return Values

## Core Idea

- `1` represents land.
- `0` represents water.
- An island is a group of connected land cells.
- The area is the number of land cells in that island.

We must return the largest island area.

## Approach

1. Traverse every cell using nested loops.
2. When `grid[i][j] == 1`, start DFS.
3. DFS calculates the area of the entire connected island.
4. Update the maximum using:

   `maxArea = Math.max(dfs(grid, i, j), maxArea);`

5. Return `maxArea`.

## How DFS Calculates Area

### Base cases

Return `0` when:
- The coordinates are outside the grid.
- The current cell is water (`0`).

These cells contribute no land area.

### Mark visited

`grid[row][col] = 0;`

This prevents the same land cell from being counted repeatedly.

### Calculate the area

Return:

`1 + dfs(up) + dfs(down) + dfs(left) + dfs(right)`

Why `1`?

The current cell is land, so it contributes one unit of area.

The four recursive calls calculate the areas contributed by connected land in each direction.

## Example

Grid:

1 1 0
1 0 0
0 1 1

The first island has area `3`.

The second island has area `2`.

Therefore, the answer is `3`.

## Why Use Math.max()?

Each DFS call returns the area of one island.

`maxArea` stores the largest area found so far.

For every new island:

`maxArea = Math.max(currentIslandArea, maxArea);`

If the current island is larger, update the maximum. Otherwise, keep the existing maximum.

## Edge Cases

- All water: return `0`.
- One land cell: return `1`.
- All land in one connected region: return `m × n`.
- Multiple islands of different sizes: return the largest area.
- Diagonally adjacent land cells are not connected.
- A grid with one row or one column must still work.

## Common Mistakes

1. Counting islands instead of calculating their areas.
2. Forgetting the `1` for the current land cell.
3. Forgetting to mark a land cell as visited before recursion.
4. Returning `1` for water or out-of-bounds cells instead of `0`.
5. Updating `maxArea` incorrectly.
6. Forgetting that the grid is modified in place.

## Complexity

Let:
- m = number of rows
- n = number of columns

Time: O(m × n)

Each cell is processed at most a constant number of times.

Auxiliary space: O(m × n) worst case.

The recursive DFS stack can grow to O(m × n) in the worst case.

The grid is used to mark visited cells, so no separate visited array is required.

## Interview Takeaways

- Number of Islands counts connected components.
- Max Area of Island calculates the size of each component.
- Returning a value from DFS lets you combine results from neighboring cells.
- `1 + dfs(up) + dfs(down) + dfs(left) + dfs(right)` is the key area-calculation pattern.
- `Math.max()` tracks the largest component found.
